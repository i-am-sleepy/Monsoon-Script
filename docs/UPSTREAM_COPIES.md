# KeePassDX code copied or adapted into our own files (D46)

The engine modules (`:database`, `:crypto`) are used UNCHANGED through the git submodule `third_party/keepassdx` (D47) and are never listed here.
Every piece of KeePassDX code that we COPY or ADAPT (for example from its `:app` module) gets one line here: our file, the upstream file, the upstream release tag it
was taken from, why we copied it instead of writing our own, and how to re-sync it. Each such file keeps its GPL header and lives in its own package.
The owner is told when a non-trivial piece is taken (D46).
