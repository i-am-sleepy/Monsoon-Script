# Monsoon Script

A fast, lightweight Android keyboard for English and Bangla (Avro Phonetic, Provat, Bijoy) with a clean Gboard-style look
and proper physical-keyboard support. Work in progress.

## Continuing the project from any Claude chat
The repo is the shared memory: `CLAUDE.md` (rules) and `STATUS.md` (where we are, what's next). Paste this into a new chat
after connecting the GitHub repo (add what you want done at the end, or leave it to continue from "Next step"):

> Continue my Android keyboard project in github.com/i-am-sleepy/Monsoon-Script. Read CLAUDE.md, then STATUS.md, and
> continue from "Next step". Commit straight to main and keep STATUS.md updated. My request: ...

Tip for the owner: say "checkpoint" at any time and the agent pushes its work and updates STATUS.md immediately.

## Layout
`CLAUDE.md` agent rules · `STATUS.md` baton and the only task list · `DECISIONS.md` settled choices ·
`ARCHITECTURE.md` code map · `docs/REQUIREMENTS.md` feature spec · `third_party/avro-reference/` MPL-2.0 reference sources
